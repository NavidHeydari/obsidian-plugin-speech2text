# Obsidian Speech2Text Plugin — MVP 2 Design Spec

**Date:** 2026-06-11
**Status:** Approved

## Overview

MVP 2 adds live microphone capture to the plugin. The user can start, pause, and stop recording from a floating panel opened via the ribbon button, or trigger start/stop externally via an AutoHotkey hotkey that hits a local HTTP control server. Stopping recording automatically transcribes the audio and saves a timestamped note — same pipeline as MVP 1.

---

## Architecture

Five modules (two new, three updated):

| File | Status | Responsibility |
|---|---|---|
| `src/recorder.ts` | New | `getUserMedia` + `MediaRecorder` state machine; start/pause/resume/stop; saves `.webm`; 7-day cleanup |
| `src/recording-panel.ts` | New | Floating panel UI (extends `Modal`); Start/Pause/Resume/Stop/Browse buttons; reflects recorder state |
| `src/control-server.ts` | New | Node.js HTTP server on port 27183; `/toggle`, `/start`, `/stop`, `/status` endpoints |
| `src/main.ts` | Update | Wires recorder + panel + control server; ribbon opens panel; shared `transcribe` callback |
| `src/settings.ts` | Update | Adds Control Server section (enable toggle, port field, AHK snippet) |

### Data Flow

```
AHK hotkey → HTTP → control-server → recorder.stop() → transcribe callback → whisper-client → note-creator
ribbon click → recording-panel → recorder.start/pause/stop() → transcribe callback → whisper-client → note-creator
Browse button → recording-panel → file input → transcribe callback → whisper-client → note-creator
```

The `transcribe(blob, fileName)` callback lives in `main.ts` and is the single shared path to whisper-client and note-creator — panel and control server both receive it and never import whisper-client directly.

## Module Designs

### `recorder.ts`

A state machine with four states:

```
idle ──start()──→ recording ──pause()──→ paused
                     │                     │
                   stop()             resume() ──→ recording
                     │                     │
                     └─────────────────────┘
                               ↓
                    save .webm → return { blob, fileName }
```

**Public API:**

```typescript
class Recorder {
  getState(): 'idle' | 'recording' | 'paused'
  async start(): Promise<void>
  pause(): void
  resume(): void
  async stop(): Promise<{ blob: Blob; fileName: string }>
  async cleanup(pluginDir: string): Promise<void>
}
```

**Audio capture:** `getUserMedia({ audio: true })` → `MediaRecorder` collecting chunks on `dataavailable`. On `stop()`, chunks are assembled into a single `Blob` (WebM/Opus — native format, no conversion needed).

**File saving:** After stop, the blob is written to `<pluginDir>/recordings/YYYY-MM-DD_HH-MM-SS.webm` using Node.js `fs.promises`. The path is returned alongside the blob so the caller can pass the correct filename to the Whisper API.

**Cleanup:** Deletes any `.webm` file in the recordings folder older than 7 days. Runs on plugin load and after each recording completes.

**Error handling:** If `getUserMedia` is denied or unavailable, `start()` throws with a descriptive message. The panel catches this and shows an Obsidian `Notice`.

### `recording-panel.ts`

Extends Obsidian `Modal`. Opened by the ribbon button. Receives the `Recorder` instance and the `transcribe` callback from `main.ts`.

**Layout:**

```
┌─────────────────────────────────┐
│  Speech2Text                    │
│                                 │
│  [▶ Start]  [⏸ Pause]  [⏹ Stop] │
│                                 │
│  ──────────── or ────────────── │
│                                 │
│  [📂 Browse File]               │
│                                 │
│  Status: Idle                   │
└─────────────────────────────────┘
```

**Button states by recorder state:**

| State | Start | Pause/Resume | Stop | Browse |
|---|---|---|---|---|
| `idle` | enabled | disabled | disabled | enabled |
| `recording` | disabled | "Pause" enabled | enabled | disabled |
| `paused` | disabled | "Resume" enabled | enabled | disabled |

**Behaviours:**

- **Start** — calls `recorder.start()`; updates button states and status line to `Recording…`
- **Pause** — calls `recorder.pause()`; button label flips to "Resume"; status line shows `Paused`
- **Resume** — calls `recorder.resume()`; button label returns to "Pause"; status line shows `Recording…`
- **Stop** — calls `recorder.stop()` to get `{ blob, fileName }`; shows `Notice("Transcribing…", 0)`; calls `transcribe(blob, fileName)`; closes panel on success, hides notice and shows error notice on failure
- **Browse** — triggers a hidden `<input type="file">` (same accepted formats as MVP 1); on file selected, calls `transcribe(file, file.name)`

### `control-server.ts`

Bare Node.js `http` server (no Express). Binds to `127.0.0.1` only (localhost — not exposed on the network).

**Public API:**

```typescript
class ControlServer {
  constructor(port: number, recorder: Recorder, onStop: () => Promise<void>)
  start(): void
  stop(): void
}
```

`onStop` is the callback invoked when the server triggers a recording stop — it calls `recorder.stop()` then the shared `transcribe` callback from `main.ts`.

**Endpoints:**

| Endpoint | Behaviour |
|---|---|
| `GET /toggle` | idle → start recording; recording/paused → stop + transcribe |
| `GET /start` | no-op if already recording or paused; otherwise start |
| `GET /stop` | no-op if idle; otherwise stop + transcribe |
| `GET /status` | `200 {"recording": true\|false, "state": "idle"\|"recording"\|"paused"}` |

All endpoints return `200` with a JSON body. Unknown paths return `404 {"error": "not found"}`.

**Port conflict:** If the port is already in use at startup, the server logs the error and shows a one-time `Notice("Speech2Text: control server failed to start — port <n> already in use")`. The rest of the plugin continues working normally.

### `settings.ts` updates

New fields added to `PluginSettings`:

```typescript
controlServerEnabled: boolean  // default: true
controlServerPort: number      // default: 27183
```

New "Control Server" section in the settings tab (appended after existing sections):

- **Enable control server** — toggle (default: on)
- **Port** — number input (default: 27183); changing port requires reloading the plugin
- **AutoHotkey v2 snippet** — read-only `<pre>` block with a "Copy" button

AHK snippet shown in settings (port substituted from settings):

```autohotkey
; Save as recording.ahk and run it at Windows startup
^+R::  ; Ctrl+Shift+R — change to any key combo
{
    http := ComObject("WinHttp.WinHttpRequest.5.1")
    http.Open("GET", "http://localhost:27183/toggle", false)
    http.Send()
}
```

### `main.ts` updates

On `onload()`:
1. Instantiate `Recorder`
2. Run `recorder.cleanup(pluginDir)` to purge old recordings
3. If `settings.controlServerEnabled`, instantiate and start `ControlServer`, passing `recorder` and the `transcribe` callback
4. Register ribbon icon — click opens `RecordingPanel` passing `recorder` and `transcribe` callback

Shared `transcribe` method on the plugin class:

```typescript
async transcribe(blob: Blob, fileName: string): Promise<void> {
  const notice = new Notice('Transcribing…', 0);
  try {
    const transcript = await transcribeAudio(blob, fileName, this.settings);
    const noteName = await createNote(this.app, transcript, this.settings);
    notice.hide();
    new Notice(`Saved → ${noteName}`);
  } catch (err) {
    notice.hide();
    new Notice(`Transcription failed: ${(err as Error).message}`);
  }
}
```

On `onunload()`: stop `ControlServer` if running.
